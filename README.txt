차현진 | SW·AI 코딩융합교육 강사 (2026)

[파일 안내]
- index.html: HTML, CSS, JavaScript가 한 파일에 포함된 반응형 웹사이트
- README.txt: 배포 방법

[바로 실행]
index.html 파일을 Chrome/Edge 브라우저에서 열면 됩니다. 설치가 필요 없습니다.

[GitHub Pages 게시]
1. 본인 GitHub에서 새 공개 저장소를 만듭니다. (예: sw-ai-portfolio)
2. 압축을 풀어 index.html 파일을 저장소 루트에 업로드합니다.
3. 저장소의 Settings → Pages → Build and deployment → Deploy from a branch를 선택합니다.
4. Branch: main, Folder: /(root)를 선택하고 Save합니다.
5. GitHub Pages에 표시된 주소를 방문해 확인합니다.
